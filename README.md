# 法治服务器（Rule of Law）— Minecraft Forge 1.20.1 模组

监测玩家行为，依据《中华人民共和国刑法》与《宪法》进行游戏内审判与惩罚。
加载模组后自动在 (1000, 180, 1000) 高空生成一座**基岩监狱**（8 间牢房，区块强加载）。
所有刑期**按游戏时间计算**（1 游戏日 = 现实 20 分钟），最长不超过 **10 个游戏日**。
有问题QQ:3684078503

## 一、罪名与刑罚一览

| 触发行为 | 罪名 | 法条 | 刑罚 |
|---|---|---|---|
| 击杀玩家 | 故意杀人罪 | 刑法第232条 | 8~10 天监禁 + 附加剥夺政治权利（禁言）+ 罚金；**第3次起判处死刑** |
| 击杀村民 | 故意杀人罪（杀害村民） | 刑法第232条 | 5~8 天监禁 |
| 攻击玩家 | 故意伤害罪 | 刑法第234条 | 第1次警告+罚金 → 第2次管制2天 → 第3次起监禁1~3天 |
| 杀熊猫/美西螈/海豚/海龟/北极熊/嗅探兽 | 危害珍贵、濒危野生动物罪 | 刑法第341条 | 2~5 天监禁 + 罚金 |
| 一天猎杀普通动物超过 10 只 | 非法狩猎罪 | 刑法第341条第2款 | 罚金+管制1天，再犯拘役1天 |
| 放置火焰（打火石点火） | 放火罪 | 刑法第114条 | 3~5 天监禁 |
| 引爆 TNT | 爆炸罪 | 刑法第115条 | 5~8 天监禁（放置 TNT 时先行警告）；**第3次起判处死刑** |
| 在其他玩家 6 格内开箱子 | 盗窃罪 | 刑法第264条 | 第1次警告 → 第2次罚金 → 第3次起监禁1~2天 |
| 在村庄 32 格内破坏方块 | 故意毁坏财物罪 | 刑法第275条 | 第1次警告 → 第2次罚金 → 第3次起监禁1~2天 |
| 8 秒内刷屏 5 条消息 | 寻衅滋事罪 | 刑法第293条 | 禁言1天，再犯禁言2天+管制1天 |

> **罚金 = 扣除生命值**（不再扣经验等级）。**死刑**：故意杀人罪、爆炸罪第 3 次触犯时触发，
> 直接击杀玩家（死刑立即执行），重生点自动重置回世界出生点。

**宪法元素**：逮捕广播援引宪法第37条（非经法院决定不受逮捕）；
特赦命令援引宪法第67、80条。

**刑罚种类**：警告 / 罚金（扣生命值）/ 管制（缓慢+虚弱的社区矫正）/ 剥夺政治权利（禁言）/ 有期徒刑（基岩监狱服刑）/ 死刑（直接击杀）。
**累犯从重**：同一罪名第 3 次触犯直接顶格量刑（前科记录存档持久化）；故意杀人罪、爆炸罪第 3 次触犯判处死刑。
**死亡不掉落**：模组强制开启全员死亡不掉落（背包物品 + 经验均保留），任何原因死亡（含死刑、摔死、被杀）都不掉装备。

**监狱设施**：每间牢房含红色床铺、补给箱（面包 x16 / 苹果 x8 / 熟牛排 x4）、荧石 + 地板火把 + 悬挂灯笼照明。
**重生点机制**：收监时重生点锁定在牢房；刑满释放或获特赦/死刑时，重生点重置为世界出生点；
即使离线期间刑满，登录时检测到人/重生点仍在监狱也会自动送回出生点，不会被困。

**反越狱机制**：基岩结构 + 每秒巡逻检测（离开牢房立即押回）+ **越狱未遂加刑 1 天**（30 秒冷却防刷，总刑期仍封顶 10 天）+ 禁用末影珍珠/紫颂果
+ 重生点锁定在牢房 + 服刑期间禁止破坏方块。
**减刑（悔改表现）**：依据刑法第78条，在押期间老实待在牢房（不越狱），每满 1 个游戏日自动减刑 1 天，
最多减至**原判刑期的一半**；越狱 1 次清零良好表现，越狱 2 次起取消减刑资格。

## 二、命令

- `/law` — 帮助
- `/law crimes` — 查看全部罪名与法条
- `/law prisoners` — 查看在押人员与剩余刑期
- `/law pardon <玩家>` — 发布特赦令（需 OP 权限）

## 三、打包方法（需一台电脑，手机无法完成 Forge 构建）

1. **装 JDK 17**：https://adoptium.net 下载 **Temurin 17** 并安装。
2. **下载 MDK**：https://files.minecraftforge.net → 选 **1.20.1** → 下载 MDK 并解压
   （工程里没含的，首次构建会自动下载几百 MB 依赖，请保持网络通畅）。
3. **合并工程**：把本工程的 `src` 目录整体替换 MDK 的 `src`，
   再用本工程的 `build.gradle`、`settings.gradle`、`gradle.properties` 覆盖 MDK 中的同名文件。
4. **构建**：在 MDK 目录下执行
   - Windows：`gradlew.bat build`
   - Mac/Linux：`./gradlew build`
5. **取成品**：构建产物为 `build/libs/ruleoflaw-1.0.0.jar`，
   把它丢进 Forge 1.20.1 服务端/客户端的 `mods` 文件夹即可。

> 详细教程、常见问题、自定义修改点（改监狱位置、刑期上限、加新罪名）都在本 README 中。
> 注：多人合租基地可能误伤，可在 `BehaviorMonitor.onContainerOpen` 里调大冷却或加白名单。

```bash
./gradlew runServer   # 启动测试服务端
```

## 四、常见问题

- **想改监狱位置/规模**：修改 `PrisonManager.ORIGIN` 与 `CELLS`。
- **想改最长刑期**：修改 `RuleOfLawMod.MAX_PRISON_DAYS`。
- **想加新罪名**：在 `CrimeType` 加枚举 → `BehaviorMonitor` 加事件监听 → `CourtSystem.decideAndApply` 加量刑分支。

## 五、项目结构

```
RuleOfLawMod/
├── build.gradle / settings.gradle / gradle.properties   # 构建配置（ForgeGradle 6）
└── src/main/
    ├── java/com/ruleoflaw/
    │   ├── RuleOfLawMod.java          # 主类（MOD_ID、全局常量）
    │   ├── crime/CrimeType.java       # 罪名枚举（罪名、法条、量刑范围）
    │   ├── court/CourtSystem.java     # 法院：公诉、判决、执行（罚金/禁言/管制/监禁）
    │   ├── monitor/BehaviorMonitor.java# 行为监控：全部游戏事件入口
    │   ├── prison/PrisonManager.java  # 基岩监狱：生成、收监、释放、防越狱
    │   ├── prison/PrisonData.java     # SavedData 存档：犯人/禁言/管制/前科
    │   └── command/LawCommands.java   # /law 命令（含特赦）
    └── resources/
        ├── META-INF/mods.toml         # 模组元数据
        └── pack.mcmeta
```
